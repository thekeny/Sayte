### Правила работы

- README.md не изменяй, если пользователь прямо не попросил изменить его.
- Соблюдай корневой AGENTS.md: двойные кавычки, camelCase для функций,
  импорты без скобок, остальное по PEP 8. Не добавляй комментарии в код
  и переназначения функций ради псевдонимов.
- Не используй pathlib.Path. Приложение запускается из папки sayte;
  пути задавай строками относительно неё.
- Пути к ресурсам, константы, словари сообщений и настроек храни
  в config.py. Обращайся к ним через import config.
- Окна и расположение элементов храни в .ui-файлах. Python отвечает
  за загрузку форм, сигналы и логику.
- Проверочные скрипты и тесты держи вне sayte, в ../.local-checks/sayte.
  Эта папка исключена из Git и не входит в итоговый проект.
  Не добавляй тесты и инструкции по их запуску в сдаваемый проект.
  Для локальной проверки запускай из sayte:
  python -m unittest discover -s ../.local-checks/sayte -v

### Неочевидные ограничения

- HTTP и распознавание выполняются в рабочих потоках; SQLite и виджеты —
  только в главном. Не уничтожай окна или потоки до завершения работы.
- Применение ответа ИИ и досказанная запись меняют только редактор.
  Запись в базу выполняется кнопкой сохранения. original_text не изменяй.
  При ошибке сохранения не теряй текст и возможность повторной попытки.
- Подключения, модели и управление своими действиями находятся только
  в настройках. Не возвращай технические поля в окно обработки заметки
  и выбор типа API в настройки подключения.
- Общий системный промпт задаёт формат ответа; действие и текст заметки
  передаются пользовательским сообщением. Не отправляй текст и платные
  запросы автоматически и не повторяй их без действия пользователя.
- Изменения профилей до сохранения остаются в памяти диалога.
  API-ключи не должны попадать в ошибки и логи. Локальные API могут
  работать без ключа.
- Горячая клавиша глобальная, через Windows RegisterHotKey. В открытом
  редакторе она управляет досказыванием, а не созданием другой заметки.
- Крестик главного окна скрывает его в трей; выход — отдельное действие.
  При недоступности трея крестик завершает приложение с проверкой
  незавершённой работы.
- Whisper скачивается без токена Hugging Face и без Xet, затем работает
  с локальным кешем. Аудио хранится только в памяти.
