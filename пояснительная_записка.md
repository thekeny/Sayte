# Пояснительная записка

## Sayte (Say Note)

Автор: Маратканов Артем Андреевич

## 1. Описание проекта

Название: Sayte (Say Note)

Идея: Десктопное приложение на PyQT6 для быстрой голосовой записи мыслей по нажатию горячей клавиши с последущей распознованием и переводом в текст через локальную модель Whisper, после чего текст сохраняется и отображается среди всех записей
При желании человек может редактировать заметку вручную или с помощью внешних ИИ-провайдеров (к примеру OpenRouter добавленый по умолчанию, Routerai.ru, локальных моделей Ollama и др.)

Цель: ускорить фиксацию мыслей и идей без необходимости открывать отдельные приложения и ввода руками

Целевая аудитория: студенты, разработчики и все, кто часто записывать идеи во время работы за компьютером

Приложение позволяет записать мысль во время работы за компьютером, а затем найти,
отредактировать и сохранить её как текстовую заметку. Основной сценарий объединяет
голосовую запись, локальное распознавание и обработку текста в одном приложении.

## 2. Задачи проекта

Для достижения цели были поставлены следующие задачи:

- Реализовать запись аудио с микрофона и управление глобальной горячей клавишей.
- Подключить локальное распознавание речи через Whisper.
- Создать интерфейс просмотра и редактирования заметок.
- Организовать хранение заметок, тегов и настроек в SQLite.
- Добавить поиск, фильтрацию, удаление и экспорт заметок.
- Реализовать подключение ИИ-провайдеров и предпросмотр результата обработки.
- Выполнять распознавание и HTTP-запросы в фоне, не блокируя интерфейс.
- Собрать приложение в единый исполняемый файл для Windows.

## 3. Пользовательский путь

1. Запуск приложения и открытие главного окна; при автозапуске Windows — работа в трее.
2. При нажатии горячей клавиши появляется окно и начинается запись голоса
3. Повтороное нажатие горячей клавиши останавливает запись
4. Записанное аудио начинате обработку и преобюразование в текст в фоне через Whisper
5. Создается новая заметка с сказаным текстом, которая автоматически сохраняется в БД SQLite
6. По иконке в трее открывается главное окно со списком всех заметок.
7. В основном приложении можно:

- Просматривать и редактировать содержимое заметки
- Искать заметки по содержимому
- Добавлять теги и фильтровать заметки
- Удалять ненужные заметки
- Редактировать заметки с помощью запросов к ИИ-провайдеру

8. Пользователь отправляет текст и запрос ИИ-провайдеру, просматривает ответ и принимает или отклоняет изменения. Для записи принятых изменений в базу нужно сохранить заметку.

(По умолчанию) Ctrl+Alt+R начинает запись с микрофона, повторное нажатие останавливает её

Обычный запуск показывает главное окно. Автозапуск Windows использует режим запуска
в трее. Закрытие главного окна скрывает его в трей; для завершения приложения
предусмотрено отдельное действие. Если системный трей недоступен, закрытие главного
окна завершает приложение с проверкой незавершённой работы.

## 4. Возможности приложения

### 4.1. Запись и распознавание голоса

- Запуск и остановка записи глобальной горячей клавишей
- Настройка горячей клавиши
- Запись аудио с микрофона
- Локальное распознавание речи через Whisper
- Отображение состояния записи и распознавания
- Обработка ошибок записи и распознавания (К примеру если не удалось распознать речь)

Во время записи отображается волна звука, а при распознавании — индикатор
обработки. В открытом редакторе можно досказать существующую заметку.
Дополнительный текст попадает в редактор и сохраняется кнопкой «Сохранить».

### 4.2. Работа с заметками

- Автоматическое создание заметки после распознавания
- Отображение списка всех заметок
- Просмотр получившийся заметки
- Ручное редактирование заметки
- Удаление заметки
- Поиск заметок по тексту и названию
- Добавление и удаление тегов
- Фильтрация заметок по тегам
- Хранение исходного содержимого заметок
- Экспорт заметки в TXT

Дополнительно реализовано закрепление заметок: закреплённые записи показываются
выше остальных. Высоту поля с текстом можно менять перетаскиванием границы под ним.

### 4.3. Интеграция с ИИ

- Подключение OpenRouter
- Подключение других ИИ-провайдерам (С OpenAI-совместимым API)
- Настройка API-ключа, URL и модели
- Встроенные режимы обработки: исправление ошибок, структурирование, краткое содержание
- Создание собственных режимов обработки с заготовлеными промптами
- Предпросмотр ответа модели
- Применение/отклонение изменений
- Обработка ошибок API

Запрос отправляется по действию пользователя. Применение ответа меняет текст
в редакторе; для записи изменений в базу нужно сохранить заметку. Исходный текст
распознавания при этом не изменяется. Запрос к ИИ также можно продиктовать голосом.

### 4.4. Интерфейс и настройки

- Главное окно со списком заметок
- Редактор выбранной заметки
- Окно настроек приложения
- Окно настройки ИИ-провайдеров
- Работа через системный трей
- Сохранение/сброс пользовательских настроек горячей клавиши
- Отображение ошибок и уведомлений

В настройках доступны светлая и тёмная темы, автозапуск вместе с Windows
и размер текста заметки от 8 до 32 пт. Размер задаётся через `QSpinBox`
и сохраняется между запусками. По умолчанию используется 12 пт.
Кнопки «Сохранить», «Отмена» и «Сбросить» объединены в `QDialogButtonBox`.
Отмена не сохраняет изменения настроек, сброс возвращает значения по умолчанию
до подтверждения сохранения.

## 5. Технологический стек

| Технология | Назначение |
| --- | --- |
| Python | Язык программирования |
| PyQt6, Qt Designer | Интерфейс, формы `.ui`, сигналы и обработка событий |
| faster-whisper | Локальное распознавание речи |
| sounddevice | Запись аудио с микрофона |
| NumPy | Хранение и объединение аудиоданных |
| SQLite3, sqlite3 | Хранение заметок, тегов, промптов, настроек и API-ключей |
| requests | HTTP-запросы к ИИ-провайдерам |
| QThread | Выполнение длительных операций в фоне |
| ctypes, RegisterHotKey | Глобальная горячая клавиша Windows |
| PyInstaller | Сборка приложения в EXE |
| requirements.txt | Список зависимостей с закреплёнными версиями |

Вызов по горячей клавише: RegisterHotKey Windows через ctypes и события Qt.
Сочетание Ctrl+Alt+R срабатывает по нажатию клавиши R (К в русской раскладке).
Если сочетание занято другим приложением, Sayte показывает ошибку регистрации.

Для интерфейса используется PyQt6 с формами Qt Designer. SQLite хранит данные
локально и не требует отдельного сервера. Whisper позволяет распознавать речь
на компьютере пользователя без отправки аудио внешнему сервису.

## 6. Архитектура

1. Глобальная горячая клавиша
2. Модуль записи аудио
3. Whisper (локально)
4. PyQt: редактор и просмотр заметок
5. SQLite
6. Модуль ИИ-провайдера
7. OpenRouter/свой API
8. Предпросмотр результата и работа с нимы

Модули:

- ui
- audio
- transcription
- ai
- database

Транскриптизация и HTTP-запросы выполняются в фоне

Основные классы и их назначение:

| Модуль | Классы и ответственность |
| --- | --- |
| `ui` | `Sayte` — главное окно; `NoteWindow` — редактор; `SettingsWindow` — настройки; `PreviewWindow` — обработка ИИ и предпросмотр |
| `audio` | `Recorder` — запись аудио; `RecordingSession` — общий контроль записи и распознавания для разных окон |
| `transcription` | `Whisper` — загрузка модели и распознавание; `TranscriptionWorker` — работа в отдельном потоке |
| `ai` | `Provider` — HTTP-запросы; `AiWorker` — выполнение запросов в рабочем потоке |
| `database` | `Database`, `Notes`, `Tags`, `Settings`, `Providers`, `Presets` — создание базы и работа с данными |
| `utils` | Глобальная горячая клавиша и автозапуск Windows |

Точка входа — `app.py`. Общие настройки, константы и пути к ресурсам находятся
в `config.py`. Расположение элементов интерфейса хранится в `.ui`-файлах,
а Python-код загружает формы и обрабатывает действия пользователя.

Общий контроллер `RecordingSession` предотвращает одновременную запись из разных
окон. Результаты фоновой работы передаются через сигналы Qt. Обновление интерфейса
и работа с SQLite выполняются в главном потоке.

## 7. Структура базы данных

notes - Название, исходный и текущий текст, даты создания и изменения

tags - Названия тегов

note_tags - Связь заметок с тегами

ai_presets - Пользовательские присеты промптов

Дополнительно используются таблицы `settings` для настроек приложения
и `ai_profiles` для подключений к ИИ. Всего в базе шесть таблиц.
В `notes` также хранится признак закрепления заметки.

База данных находится в `data/sayte.sqlite`. Таблица `note_tags` задаёт связь
«многие ко многим»: у заметки может быть несколько тегов, один тег может
относиться к нескольким заметкам. Включены внешние ключи и каскадное удаление.
В SQL-запросах используются параметры, связанные изменения сохраняются
в транзакциях.

Первоначальный результат распознавания хранится в `original_text`,
отредактированный текст — в `current_text`. Это позволяет сохранить исходник,
но не является полной историей версий с возможностью отката.

## 8. Алгоритм записи и распознавания

1. Пользователь включает запись горячей клавишей или кнопкой.
2. `Recorder` получает монофоническое аудио с частотой 16 000 Гц.
3. После остановки записи аудио передаётся в `TranscriptionWorker`.
4. При первом распознавании загружается модель Whisper `base` в `data/models`.
   Для загрузки нужен интернет; затем используется локальный кеш.
5. Модель работает на CPU с вычислениями `int8`. Выбирается русский
   или английский язык, применяется фильтрация неречевых участков.
6. Распознанные сегменты объединяются в текст.
7. Новая заметка автоматически сохраняется в SQLite и появляется в списке.
   При досказывании текст добавляется в открытый редактор.

Аудио хранится в оперативной памяти и не записывается в отдельный файл.
При обращении к ИИ-провайдеру отправляются текст заметки и запрос пользователя.

## 9. Запуск и сборка

Приложение рассчитано на Windows. Для запуска исходного кода команды
выполняются из папки проекта.

Запуск в Windows

```
pip install -r requirements.txt
python app.py
```

Сборка в Windows

```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --clean --noconfirm Sayte.spec
```

Файл `Sayte.spec` задаёт сборку в единый EXE и включает формы, изображения
и необходимые библиотеки. Результат сборки — `dist/Sayte.exe`.
Если старый рабочий каталог сборки недоступен для очистки, можно указать новый
каталог параметром `--workpath` и выполнить сборку без `--clean`.

Для запуска готового EXE установка Python не нужна. Данные и кеш модели
создаются рядом с EXE, поэтому папка приложения должна быть доступна для записи.
Для внешнего ИИ нужно настроить подключение и доступ к выбранному API.
Локальный OpenAI-совместимый API может работать без ключа и без интернета.

## 10. Проверка работы

Выполнена автоматическая проверка основных сценариев приложения:
все 41 локальный тест прошли. Проверялись работа с базой, сохранение исходного
текста, поиск, теги, TXT-экспорт, обработка ответов и ошибок API,
управление записью, настройки размера текста, отмена и сброс настроек.
Также выполнена проверка Ruff на ошибки, неиспользуемые импорты
и форматирование по выбранным правилам.

Приложение собрано в единый EXE. В отдельной временной папке проверены
два запуска собранного приложения, создание базы и сохранение данных
между запусками.

Полная ручная проверка с настоящим микрофоном, моделью Whisper
и ИИ-провайдером, а также запуск EXE на другом компьютере без Python
остаются отдельными этапами проверки перед сдачей.

## 11. Риски и ограничения

- Интернет ИИ-функционала
- Производительность локального Whisper
- Конфликт горячих клавиш с другими приложениями
- Ошибки распознования речи
- Доступность внеших API

Интернет необходим для первой загрузки модели Whisper и обращения к внешним
ИИ-провайдерам. После загрузки модели распознавание работает локально.
Скорость обработки зависит от компьютера, точность — от качества записи,
произношения и шума. В текущей реализации выбирается русский или английский язык.
Глобальная горячая клавиша и автозапуск реализованы для Windows.

Заметки, настройки и API-ключи хранятся в локальной SQLite без шифрования.
При ошибке сохранения текст остаётся доступен для повторной попытки.

## 12. Результаты и дальнейшее развитие

В проекте реализован основной сценарий голосовой заметки: запись с микрофона,
локальное распознавание, создание записи в SQLite, просмотр и редактирование.
Добавлены теги, поиск, закрепление, TXT-экспорт, работа через трей,
настройки оформления и обработка текста через ИИ с предпросмотром результата.

Во время разработки использованы классы и модули Python, формы Qt Designer,
сигналы и события Qt, стандартные диалоги, файлы, реляционная база данных,
рабочие потоки и HTTP-запросы. Дополнительно реализованы глобальная горячая
клавиша и собственные рисуемые виджеты волны записи и индикатора обработки.
