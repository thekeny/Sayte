# Sayte — голосовые заметки

Проект для Яндекс Лицея в курсе "Промышленного программирования на Python" по PyQT

### 1. Описание

Название: Sayte (Say Note)

Автор: Маратканов Артем Андреевич

Материалы: [презентация](Sayte.pdf),
[пояснительная записка](ExplanatoryNote.md).

Идея: Десктопное приложение на PyQT6 для быстрой голосовой записи мыслей по нажатию горячей клавиши с последущей распознованием и переводом в текст через локальную модель Whisper, после чего текст сохраняется и отображается среди всех записей
При желании человек может редактировать заметку вручную или с помощью внешних ИИ-провайдеров (к примеру OpenRouter добавленый по умолчанию, Routerai.ru, локальных моделей Ollama и др.)

Цель: ускорить фиксацию мыслей и идей без необходимости открывать отдельные приложения и ввода руками

Целевая аудитория: студенты, разработчики и все, кто часто записывать идеи во время работы за компьютером

Запуск в Windows
```
pip install -r requirements.txt
python app.py
```

Сборка в Windows
```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --clean --noconfirm Sayte.spec
```

(По умолчанию) Ctrl+Alt+R начинает запись с микрофона, повторное нажатие останавливает её

### 2. Пользовательский путь

1. При обычном запуске открывается главное окно. Автозапуск Windows запускает приложение в трее.
2. При нажатии горячей клавиши появляется окно и начинается запись голоса
3. Повтороное нажатие горячей клавиши останавливает запись
4. Записанное аудио начинате обработку и преобюразование в текст в фоне через Whisper
5. Создается новая заметка с сказаным текстом, которая автоматически сохраняется в БД SQLite
6. По иконке в трее открывается главное окно со списком всех заметок.
7. В основном приложении можно:
- Просматривать и редактировать содержимое заметки
- Искать заметки по содержимому
- Добавлять теги и фильтровать заметки
- Удалять ненужные заметки
- Редактировать заметки с помощью запросов к ИИ-провайдеру
8. Пользователь отправляет текст и запрос выбранному ИИ-провайдеру, просматривает ответ и принимает или отклоняет изменения. Принятые изменения записываются в базу кнопкой «Сохранить».

В открытом редакторе горячая клавиша управляет досказыванием текущей заметки.
Новый текст добавляется в редактор и сохраняется кнопкой «Сохранить».
Закрытие главного окна скрывает его в трей; выход выполняется отдельным действием.
Если трей недоступен, закрытие окна завершает приложение после проверки незавершённой работы.

### 4. Технологический стек

Язык: Python 
GUI: PyQT6
Распознование: faster-whisper
Запись аудио: sounddevice
Вызов по горячей клавише: RegisterHotKey Windows через ctypes и события Qt.
Сочетание Ctrl+Alt+R срабатывает по нажатию клавиши R (К в русской раскладке).
Если сочетание занято другим приложением, Sayte показывает ошибку регистрации.
База данных (хранение заметок, тегов, промптов, настроек и API-ключа): SQLite3
Обработка текста*: OpenRouter или любой OpenAI-совместимый API
HTTP-запросы: requests
Сборка приложениня: PyInstaller
Зависимости: requirements.txt

* Для внешнего API нужен интернет. Локальный OpenAI-совместимый API
может работать без интернета и без ключа.

### 5. Архитектура

1. Глобальная горячая клавиша
2. Модуль записи аудио
3. Whisper (локально)
4. PyQt: редактор и просмотр заметок
5. SQLite
6. Модуль ИИ-провайдера
7. OpenRouter/свой API
8. Предпросмотр результата и работа с нимы

Модули:
- ui
- audio
- transcription
- ai
- database
- utils

Транскрипция и HTTP-запросы выполняются в рабочих потоках `QThread`.
Общий контроллер `RecordingSession` управляет записью из разных окон.
SQLite и интерфейс работают в главном потоке. Формы хранятся в `.ui`,
пути и константы — в `config.py`.

### 6. Структура базы данных

notes — название, исходный и текущий текст, даты создания и изменения, закрепление

tags - Названия тегов

note_tags - Связь заметок с тегами

ai_presets - Пользовательские присеты промптов

settings — настройки приложения

ai_profiles — подключения к ИИ: URL, API-ключ и модель

Всего шесть таблиц. База находится в `data/sayte.sqlite`.
Включены внешние ключи и каскадное удаление; SQL-запросы используют параметры.
Исходный текст `original_text` сохраняется при редактировании `current_text`.
