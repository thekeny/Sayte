# PyQT Project

### 1. Описание

Название: Sayte (Say Note)

Запуск в Windows: `pip install -r requirements.txt`, затем `python app.py`.

Ctrl+Alt+R начинает запись с микрофона, повторное нажатие останавливает её.

### Текущий MVP

При запуске открывается список заметок. Запись можно начать и остановить
горячей клавишей, кнопкой главного окна или через меню в трее. Во время
записи появляется небольшое окно с состоянием и кнопкой остановки.

После остановки Whisper распознаёт речь в фоне, затем текст автоматически
сохраняется в SQLite. Сверху окна находится логотип Sayte, ниже — карточки
заметок с заголовком и первой строкой текста, снизу — кнопка записи.
Новая заметка появляется первой в списке. Нажатие на карточку открывает
редактор заметки. Название берётся из первых 60 символов
первой строки.
Нажатие на заметку открывает редактор текста с кнопками «Сохранить», «Отмена»
и «Экспорт в TXT». Экспортируется текущий текст редактора в UTF-8.
Кнопка с микрофоном позволяет досказать заметку: повторное нажатие
останавливает запись, после распознавания текст добавляется в конец редактора.
Добавленный текст сохраняется кнопкой «Сохранить».
В настройках можно изменить горячую клавишу или вернуть сочетание по умолчанию.
Поиск, удаление, теги и ИИ пока не реализованы.

Используется Whisper `base` на CPU с `int8` и автоматическим определением
языка. При первом распознавании публичная модель скачивается из интернета
без аккаунта и токена Hugging Face, обычным HTTP без Xet. Модель хранится
в `data/models`, затем используется локальная копия без обращения к сети.
Тишина и пустой результат не сохраняются.
Аудио хранится только в памяти до завершения обработки.

Заметки находятся в `data/sayte.sqlite` рядом с `app.py` и сохраняются между
запусками. При ошибке сохранения текст остаётся в памяти приложения:
кнопка «Повторить сохранение» позволяет попробовать снова.

Крестик главного окна скрывает его в системный трей. Нажатие на иконку
возвращает окно; пункт «Выход» полностью завершает приложение. Если идёт
запись или распознавание, приложение предлагает дождаться сохранения.
Если системный трей недоступен, крестик завершает приложение с той же
проверкой незавершённой записи. Автозапуск и сборка EXE пока не добавлены.

Запуск из папки `sayte`:

```console
pip install -r requirements.txt
python app.py
```

Можно запускать `app.py` и из другой рабочей папки: пути к ресурсам и базе
определяются относительно файлов приложения. Если хоткей не удалось
подключить, запись остаётся доступна через кнопки и трей.

Для ручной проверки в Windows: записать фразу по хоткею, дождаться заметки,
проверить её текст, скрыть и вернуть окно через трей, перезапустить Sayte и
убедиться, что заметка осталась. При первом запуске дождаться загрузки модели.

Идея: Десктопное приложение на PyQT6 для быстрой голосовой записи мыслей по нажатию горячей клавиши с последущей распознованием и переводом в текст через локальную модель Whisper, после чего текст сохраняется и отображается среди всех записей
При желании человек может редактировать заметку вручную или с помощью внешних ИИ-провайдеров (к примеру OpenRouter добавленый по умолчанию, Routerai.ru, локальных моделей Ollama и др.)

Цель: ускорить фиксацию мыслей и идей без необходимости открывать отдельные приложения и ввода руками

Целевая аудитория: студенты, разработчики и все, кто часто записывать идеи во время работы за компьютером

### 2. Пользовательский путь

1. Запуск приложенния, работа в фоне и отображения в трее
2. При нажатии горячей клавиши появляется окно и начинается запись голоса
3. Повтороное нажатие горячей клавиши останавливает запись
4. Записанное аудио начинате обработку и преобюразование в текст в фоне через Whisper
5. Создается новая заметка с сказаным текстом, которая автоматически сохраняется в БД SQLite
6. По иконке в трее или запуску exe открывается основное приложение со списком всех заметок
7. В основном приложении можно:
- Просматривать и редактировать содержимое заметки
- Искать заметки по содержимому
- Добавлять теги и фильтровать заметки
- Удалять ненужные заметки
- Редактировать заметки с помощью запросов к ИИ-провайдеру
8. При выборе ИИ редактирования отправлять текст с введеным промптом к провайдеру и последующие принятие/отклонение изменений

### 4. Технологический стек

Язык: Python 
GUI: PyQT6
Распознование: faster-whisper
Запись аудио: sounddevice
Вызов по горячей клавише: RegisterHotKey Windows через ctypes и события Qt.
Сочетание Ctrl+Alt+R срабатывает по нажатию клавиши R (К в русской раскладке).
Если сочетание занято другим приложением, Sayte показывает ошибку регистрации.
База данных (хранение заметок, тегов, промптов, настроек и API-ключа): SQLite3
Обработка текста*: OpenRouter или любой OpenAI-совместимый API
HTTP-Запросы: requests/httpx
Сборка приложениня: PyInstaller
Зависимости: requirements.txt

* - Требует подключение к сети и доступ в интернет

### 11. Разделение файлов

- `app.py` — запуск приложения и создание главного окна.
- `ui/main_window.py` — главное окно, виджеты и обработчики действий пользователя.
- `audio/recorder.py` — запись и остановка звука с микрофона.
- `transcription/whisper.py` — преобразование записи в текст через Whisper.
- `database/database.py` — запросы к SQLite: заметки, теги и настройки.
- `ai/provider.py` — запросы к ИИ-провайдеру и получение ответа.
- `config.py` — общие значения и настройки приложения.

Модули записи, распознавания, хранения заметок и трея реализованы для MVP.
Модули ИИ остаются заготовками. Интерфейс вызывает методы сервисов и
показывает результат, а сами сервисы не создают окна. Распознавание и
загрузка модели выполняются в рабочем потоке, результат передаётся через
сигналы PyQt. Запросы к SQLite выполняются в главном потоке.

Для дизайна можно создавать окна в Qt Designer: например, сохранить главное
окно как `main_window.ui`, а окно настроек как `settings.ui`. Загружай каждый
файл через `uic.loadUi` в соответствующем классе окна. В `.ui` хранятся
расположение и свойства виджетов, а в Python — подключение сигналов и действия.
Путь к `.ui` лучше строить относительно файла Python через `Path(__file__)`,
чтобы запуск работал из любой рабочей папки. Другие окна можно добавлять в папку `ui` отдельными Python-файлами.

Файлы внутри модулей разделены по назначению:

- `ui/main_window.py` — главное окно; `settings_window.py` и
  `provider_window.py` — настройки; `recording_window.py` — состояние записи;
  `preview_window.py` — просмотр ответа ИИ; `tray.py` — системный трей.
- `audio/recorder.py` записывает звук, `utils/hotkey.py` обрабатывает
  глобальную горячую клавишу.
- `transcription/whisper.py` отвечает за модель, `transcription/worker.py` —
  за запуск распознавания в фоне.
- `ai/provider.py` обращается к API, `ai/presets.py` описывает промпты,
  `ai/worker.py` выполняет запрос в фоне.
- `database/database.py` отвечает за подключение и создание таблиц;
  `notes.py`, `tags.py`, `settings.py` и `presets.py` — за запросы
  к соответствующим данным.

Окна ИИ-провайдеров и предпросмотра ИИ, а также модули тегов
и пресетов пока остаются заготовками. Главное окно и окно записи
загружают соседние `.ui`-файлы. В Designer размещаются виджеты, в Python
подключаются сигналы и вызываются методы других модулей. База и сервисы
не зависят от окон: их можно проверять отдельно от интерфейса.
